# Чек-лист проверки — REV.3.2-RC1

Отмечать пункт выполненным только после фактической проверки. Запись в документации или расчёт не равны испытанию.

## Механика

- [ ] Фактические габариты рамы измерены.
- [ ] Плоскостность и перпендикулярность рамы проверены.
- [ ] Положение и параллельность X/Y/Z-рельсов проверены.
- [ ] Фактические длины и ход винтов Z измерены.
- [ ] Биение всех винтов Z проверено на полном обороте.
- [ ] Стол вручную проходит весь диапазон без закусывания.
- [ ] Проверены все коллизии: стол, винты, кронштейны, доки, каретки, кабели.
- [ ] Проверены нижние аварийные буферы и верхние упоры.
- [ ] Проверен кабельный пакет стола на полном ходе.
- [ ] Измерены габариты обеих головок и фактический межкареточный зазор.

## Электрика

- [ ] Сверена схема Octopus v1.1 именно используемой ревизии.
- [ ] Проверены питание и полярность EBB36/CAN.
- [ ] Проверены PE и непрерывность защитного соединения металлических частей.
- [ ] Проверены предохранители и защита сетевой цепи.
- [ ] Проверены SSR, его теплоотвод и соответствие нагрузке.
- [ ] Проверена независимая термозащита стола.
- [ ] Проверено безопасное отключение нагревателя при отказе управления.
- [ ] Проверена изоляция и отсутствие контакта сетевых проводов с подвижными частями.

## Klipper

- [ ] Реальные MCU UUID внесены локально, не в публичный репозиторий.
- [ ] Концевики проверены без движения осей.
- [ ] Направления двигателей проверены на малом перемещении.
- [ ] Фактический ход Z подтверждён измерением.
- [ ] Проверены датчики температуры при комнатной температуре.
- [ ] Нагреватели проверены отдельно и под наблюдением.
- [ ] Выполнены PID-калибровки.
- [ ] Выполнены probe z_offset и bed mesh калибровки.
- [ ] Проверены макросы парковки и переключения T0/T1.
- [ ] COPY/MIRROR остаются отключёнными до отдельного теста.
- [ ] Проверено поведение при потере связи с MCU и аварийном отключении.

## Результаты испытаний

Для каждого испытания фиксировать дату, конфигурацию, измерительный инструмент, исходные условия, результат и замечания. Не заменять фактические результаты предположениями.
