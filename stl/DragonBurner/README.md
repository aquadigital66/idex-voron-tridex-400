# Dragon Burner STL (комплект для T0 и T1)

Источник: `chirpy2605/voron` (Dragon Burner).

## Что печатать на Neptune 2 (ABS / ASA)
Настройки слайсера: сопло `0.4 мм`, слой `0.2 мм`, **4 периметра**, **5 верх/низ**, заполнение **40%**, **без поддержек**.

| Файл | Кол-во | Примечание |
|---|---|---|
| `Cowl_NoProbe.stl` | **2 шт.** | Основной кожух для T0 и T1 |
| `FanDuct_Left.stl` | **2 шт.** | Левый воздуховод обдува модели |
| `FanDuct_Right_NoProbe.stl` | **2 шт.** | Правый воздуховод обдува модели |
| `V6_Mount_Front.stl` | **2 шт.** | Передний зажим радиатора TZ V6 2.0 |
| `V6_Mount_Rear.stl` | **2 шт.** | Задний зажим радиатора TZ V6 2.0 |
| `V6_Mount_Back.stl` | **2 шт.** | Ответная планка крепления V6 (проверить при сборке) |
| `Sherpa_Mini_Mount.stl` | **2 шт.** | Площадка под экструдер HGX Lite (совместима по посадке со Sherpa Mini) |
| `Brace_Straight.stl` | **2 шт.** | Задняя распорка / крепление жгута |
| `Dragon_Burner_FanNubs.stl` | **1 компл.** | Штифты фиксации вентилятора радиатора 3010 |
| `[a]_Carrier_Dummy.stl` | **2 шт.** | Заглушка переднего окна логотипа |

> **Важно по вентиляторам:** эта версия кожуха Dragon Burner рассчитана на **2× турбины 4010 (24V)** на обдув детали и **1× осевой 3010 (24V)** на радиатор для каждой головы (итого 4× 4010 и 2× 3010 на весь принтер).
