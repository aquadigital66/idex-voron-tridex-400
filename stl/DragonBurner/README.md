# Dragon Burner STL (предварительный комплект для T0 и T1)

**Статус:** `DRAFT / ТРЕБУЕТ ПРОВЕРКИ ПОСАДОК` (не печатать серией до сверки с CAD/железом).
**Источник:** `chirpy2605/voron` (ветка `main`, директория Dragon Burner).

## Важные проверки до запуска печати на Neptune 2
1. **Каретка IDEX (`X_Carriage`):** в данном наборе отсутствуют каретки крепления к рельсе MGN12H и ремням GT2 9 мм — их необходимо спроектировать/адаптировать отдельно под нашу балку `20×40` и концевики `EBB36`.
2. **Совместимость редуктора `HGX Lite`:** деталь `Sherpa_Mini_Mount.stl` добавлена как базовый кандидат (по стандарту крепления Sherpa Mini), но перед печатью требуется сверить межосевое расстояние винтов M3 и вылет корпуса `HGX Lite`.
3. **Совместимость хотэнда `TZ V6 2.0`:** детали `V6_Mount_Front/Rear/Back.stl` рассчитаны на стандартную шейку радиатора `V6` (`Ø16 / Ø12 / Ø16 мм`); требуется проверить реальный профиль радиатора `TZ V6 2.0` и высоту сопла в нашей размерной цепи (`570.0 мм`).
4. **Охлаждение:** данная версия кожуха рассчитана на **2× турбины `4010` (24V)** на обдув модели и **1× осевой `3010` (24V)** на радиатор для каждой головы.

## Состав файлов (ориентир для проверки в CAD / слайсере)
Настройки для тестовой печати (ABS / ASA): сопло `0.4 мм`, слой `0.2 мм`, **4 периметра**, **5 верх/низ**, заполнение **40%**, **без поддержек**.
